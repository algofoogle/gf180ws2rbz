# SUPERSEDED RBZM proposal — archive only

This is the unmodified 16 November 2026 proposal, preserved before adoption of RBZM-1 on 19 November 2026. It is not for new designs. Its R1 is RBZ_VDD and R15 is GND; RBZM-1 swaps these contacts, so mating different revisions can short the supply. Use an explicitly wired adapter, never direct cross-mating. See the current PINOUT_MIGRATION.md for all 19 changes.
